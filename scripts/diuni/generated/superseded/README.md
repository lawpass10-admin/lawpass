# Superseded drafts

Earlier versions of a question, kept after a later draft was chosen.

The loader reads `generated/*.json` only — not this folder — so moving a draft
here is how a human records the pick. It is deliberately a MOVE and not a
delete: the pair is the only record of what changed between two settings of
diuni-LLM-Params.json, and that comparison is the reason the drafts exist.
